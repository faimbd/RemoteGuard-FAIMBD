কে এই সফটওয়্যারটি ব্যবহার করতে পারবেন?
যেকোনো ব্যক্তি সহজেই এটি ব্যবহার করতে পারবেন। কোনো কোডিং, আলাদা .NET ইনস্টলেশন বা রাউটার পোর্ট ফরওয়ার্ডিং প্রয়োজন নেই। প্রতিটি ব্যবহারকারীর নিজের পিসিতে আলাদা মাস্টার পাসওয়ার্ড ও নিজের ট্রাস্টেড মোবাইল সেট হবে — কোনো থার্ড-পার্টি অ্যাকাউন্ট বা সেন্ট্রাল সার্ভার নেই, ফলে আপনার গোপনীয়তা ১০০% সুরক্ষিত থাকে।

অ্যান্ড্রয়েড মোবাইল (App) RemoteGuard.apk Android 8.0 বা তার উপরের যেকোনো ফোন (ফিঙ্গারপ্রিন্ট / স্ক্রিন লক সহ)

মূল নিরাপত্তার ৩টি স্তর (3-Layer Privacy Protection)

১. ডিভাইস ট্রাস্ট (Device Trust)

প্রথমবার পেয়ারিং করলে আপনার ফোনের Android Keystore-এ একটি গোপন 256-bit HMAC ক্রিপ্টোগ্রাফিক কী সংরক্ষিত হয়। অচেনা কোনো ফোন থেকে ঢোকা সম্ভব নয়।

২. মোবাইল ফিঙ্গারপ্রিন্ট (Biometric)

প্রতিবার কানেক্ট করার আগে আপনার মোবাইলে ফিঙ্গারপ্রিন্ট বা বায়োমেট্রিক যাচাই করা বাধ্যতামূলক। অন্য কেউ আপনার আনলক ফোন নিলেও ঢুকতে পারবে না।

৩. শর্তসাপেক্ষ মাস্টার পাসওয়ার্ড

একই ট্রাস্টেড ফোন ও একই আইপি (VPN ছাড়া) হলে পাসওয়ার্ড লাগবে না — শুধু ফিঙ্গারপ্রিন্টেই সরাসরি ঢোকা যাবে। তবে IP বদলালে, VPN চালু থাকলে, বা নতুন ডিভাইস হলে মাস্টার পাসওয়ার্ড চাইবে।

২৪/৭ অলওয়েজ-অন ও লিড গার্ড

ল্যাপটপের ঢাকনা (Lid) বন্ধ রাখলেও পিসি Do Nothing মোডে চালু থাকবে এবং নিজে থেকে Sleep বা Hibernate হবে না। তবে আপনি নিজে ম্যানুয়ালি Sleep/Shutdown করলে তা স্বাভাবিকভাবেই কাজ করবে।

ধাপ ১: উইন্ডোজ পিসি সেটআপ (প্রথমবার — মাত্র ২ মিনিট)

১সফটওয়্যার চালু করুন
RemoteGuard.Host.exe ফাইলে ডাবল-ক্লিক করুন। Administrator অনুমতি (UAC) চাইলে Yes ক্লিক করুন।
২মাস্টার পাসওয়ার্ড সেট করুন
উপরের Security & Trusted Devices ট্যাবে যান। একটি শক্তিশালী পাসওয়ার্ড লিখে Set / Update Master Password বাটনে ক্লিক করুন। (এই পাসওয়ার্ডটি PBKDF2-SHA256 হ্যাশ হিসেবে নিরাপদে সংরক্ষিত থাকে।)
৩২৪/৭ অলওয়েজ-অন এবং লক-স্ক্রিন সার্ভিস চালু করুন
24/7 Power & Lock-Screen Service ট্যাবে যান এবং নিচের দুটি বাটনে ক্লিক করুন:
  • Apply 24/7 & Lid-Close Policy: ল্যাপটপের লিড বন্ধ করলেও পিসি অন থাকবে এবং অটো স্লিপ/হাইবারনেট বন্ধ হবে। (পরে আগের অবস্থায় ফিরতে Restore Default Windows Power ক্লিক করা যাবে।)
  • Install & Start 24/7 Windows Service: এটি LocalSystem ব্যাকগ্রাউন্ড সার্ভিস ইনস্টল করে, যাতে পিসি লক থাকা অবস্থায় বা রিস্টার্ট হলেও মোবাইল থেকে সরাসরি লক-স্ক্রিন দেখে আনলক ও কন্ট্রোল করা যায়।
৪ইন্টারনেট বা ওয়াই-ফাই কানেকশন প্রস্তুত করুন
Connect & Internet ট্যাবে যান:
  • যেকোনো জায়গা থেকে (মোবাইল ডেটা / অন্য ওয়াই-ফাই): Start Internet Tunnel (Cloudflare) বাটনে ক্লিক করুন। প্রথমবার cloudflared.exe নিজেই ডাউনলোড হয়ে একটি নিরাপদ wss://xxxx.trycloudflare.com/ws লিংক তৈরি হবে।
  • শুধুমাত্র একই ওয়াই-ফাই (LAN): Allow Firewall Port বাটনে ক্লিক করুন (উপরের ws://192.168.x.x:9443/ws লিংকটি ব্যবহৃত হবে)।
৫৬-ডিজিট কোড ও QR কোড তৈরি করুন
ডান পাশে Generate 6-Digit Code & QR বাটনে ক্লিক করুন। স্ক্রিনে একটি ৬ সংখ্যার কোড ও QR কোড দেখাবে (যা ১০ মিনিট কার্যকর থাকে)।

ধাপ ২: অ্যান্ড্রয়েড মোবাইল সেটআপ (প্রথমবার — মাত্র ১ মিনিট)

১অ্যাপ ইনস্টল করুন
আপনার অ্যান্ড্রয়েড ফোনে RemoteGuard.apk ফাইলটি ওপেন করে ইনস্টল করুন। (Install unknown apps অনুমতি চাইলে Allow দিন।)
২পিসির QR কোড স্ক্যান করুন
অ্যাপ ওপেন করে Scan PC QR Code বাটনে ট্যাপ করুন এবং পিসির স্ক্রিনের QR কোডটি স্ক্যান করুন। এতে Server URL এবং 6-Digit Pairing Code স্বয়ংক্রিয়ভাবে বসে যাবে।
৩ফোনটি ট্রাস্ট ও পেয়ার করুন
  • নিচের PC Master Password ঘরে আপনার মাস্টার পাসওয়ার্ড লিখুন।
  • Pair & Trust This Phone (Fingerprint) বাটনে ট্যাপ করুন এবং ফোনে ফিঙ্গারপ্রিন্ট দিন।
  • পিসির স্ক্রিনে কনফার্মেশন পপ-আপ এলে Yes ক্লিক করুন।

ধাপ ৩: প্রতিদিনের ব্যবহার ও কন্ট্রোল গাইড

ফিচার / বাটন কাজ ও ব্যবহারের নিয়ম
Connect with Fingerprint প্রতিবার অ্যাপ খুলে এই বাটনে ট্যাপ করে ফিঙ্গারপ্রিন্ট দিলেই সরাসরি পিসি স্ক্রিন চলে আসবে (একই IP ও VPN ছাড়া কোনো পাসওয়ার্ড লাগবে না)।
লক করা পিসি আনলক টুলবারে Keys → Wake Screen বা Ctrl + Alt + Del ট্যাপ করুন → Keyb বাটনে গিয়ে উইন্ডোজ PIN/পাসওয়ার্ড লিখে ⏎ (Enter) চাপুন।
ডাবল স্ক্রিন সুইচ (S1) টুলবারের সোনালী S1 বাটনে ট্যাপ করে Screen 1, Screen 2 অথবা All Screens (Combined) নির্বাচন করতে পারবেন।
ল্যান্ডস্কেপ মোড (Land/Port) সহজে মাউস ব্যবহারের জন্য ডিফল্টভাবে Landscape মোড চালু থাকে। টুলবারের Land / Port বাটন দিয়ে যেকোনো সময় স্ক্রিন ঘোরানো যাবে।
মাউস মোড (ডিফল্ট) স্ক্রিনে আঙুল ঘোরান (সোনালী কার্সার নড়বে), ১ বার ট্যাপ = Left Click, ডাবল ট্যাপ = Double Click, R-Clk বা লং-প্রেস = Right Click, ২ আঙুলে টানলে Scroll।
Touch ও Keyboard (Yes/No) অ্যাপের হোম স্ক্রিনের Remote Control Options (Yes / No) সুইচ থেকে অথবা লাইভ সেশনে Keys মেনু থেকে যেকোনো সময় Touch এবং Keyboard অন/অফ করা যাবে।
কানেকশন ডায়াগনস্টিক লগ কানেক্ট হতে কোনো সমস্যা হলে Test Connection ট্যাপ করুন এবং নিচের Connection Diagnostic Log থেকে Copy Log দিয়ে ত্রুটির কারণ দেখুন।
